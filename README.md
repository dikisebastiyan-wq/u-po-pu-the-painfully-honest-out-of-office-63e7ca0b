# The Painfully Honest Out-of-Office

Entry for make.fun competition
`u-po-pu-the-painfully-honest-out-of-office-63e7ca0b`.

`main.py` (Python 3.13) writes one original, painfully honest but polite
out-of-office auto-reply to `/output/entry.txt`. The reply admits the sender
has been avoiding their inbox for months, thanks the writer warmly, and
promises a proper answer once back — honest first, polite second, quotable
third. Deterministic: every run writes the exact same 197-character sentence.
